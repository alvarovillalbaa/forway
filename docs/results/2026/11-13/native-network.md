## Limits

This accepts one owned-host fixture set, one runtime and observed IPv4 peers.
It is not proof for arbitrary sites, universal DNS rebinding resistance, IPv6,
every TLS deployment/platform, headers not exercised, body/header fuzzing,
request admission/global abuse controls, private networks or every transient
process/whole-host disposal. It does not add shared persistence, Auth, analytics,
external providers, customer websites or full Forway acceptance. Observer promise
scheduling and a single deadline sample are not performance evidence.
