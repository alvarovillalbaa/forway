## Additional source and isolated execution requested

This adds public network and provider-credential boundaries. The workspace
instructions require approval for security changes; AGENTS.md requires a
concrete approved backend/domain/browser/CI scope. Approval requested here
covers source and isolated fixtures only, not live credentials or deployment.

1. A public crawl-document handler accepts only a fixed kind (HTML page,
   robots or sitemap) and a public URL. Reuse the importer's resolved/public
   address policy, pinned socket, default ports, redirect validation, no caller
   headers/cookies, uncompressed UTF-8, one MiB/document and eight-second
   deadline. Keep the existing HTML-only audit contract intact. New text/XML
   media profiles are explicit; reject DTD/entity declarations and malformed XML.
2. Browser-owned serial discovery follows same-host HTTP(S) links plus sitemap
   URLs/indexes, checking robots per origin first. Preserve query strings,
   remove fragments and deduplicate exact normalized URLs. A redirected foreign
   hostname is outside scope. Never fetch denied paths or silently treat a
   robots timeout/5xx as permission. Follow RFC 9309 and record refusals/errors.
   Batches stop at explicit request/byte/time limits with a visible pending
   frontier and resumable export. A drained discoverable frontier does not
   establish every page on the domain exists in the report. No hidden page sample.
3. Explicit AI comparison runs use caller-owned OpenAI, Anthropic and Google
   API keys held in tab memory, sent only in the body to a dedicated same-origin
   POST handler and then to the selected fixed official HTTPS provider origin.
   No key enters URL, logs, report, workspace, storage or another provider.
   No deployment/server key is consumed by an anonymous public caller. Model
   IDs and exact category queries are reviewed before execution; prompts do not
   inject the audited site's content or require the brand to appear. Up to five
   queries × three selected models, one bounded request per cell; no automatic
   retries after uncertain provider acceptance. Retain answer, provider/model,
   exact query, capture time, explicit citations and native usage when supplied.
   Show success/failure/unknown denominators by provider and query cohort.
   API answers are not ChatGPT/Claude/Gemini consumer-product or Google AI
   Overview measurements. Web-grounded and ungrounded modes remain distinct.
4. Qualify new pure/controller/API-adapter cases with T2 authored data only.
   Include robots/sitemaps, cancellation/resume, foreign redirects, parser
   refusal, exact report denominators, priority grouping, prompt escaping,
   cross-provider credential isolation and uncertain provider responses.
   One isolated temporary public CI branch/workflow may install pinned browser
   tools and run desktop/390px actual UI journeys with authored local HTTP
   responses. Total owned job execution is capped at 20 minutes, with explicit
   cancellation/cleanup, source vectors, complete command streams and retained
   failures. Disable branch deployments atomically before publishing the ref;
   main and the hosted project stay unchanged. Delete the owned ref afterwards.

No migration, database/account/Auth change, dependency in the application,

Temporary CI commits/branch are only for this named approved packet. Live
